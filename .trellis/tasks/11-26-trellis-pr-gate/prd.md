# 为 AI 辅助开发设置 Trellis PR 门禁

## 目标

在 PR 模板提供 AI 使用声明。作者勾选后，检查 PR 整体差异是否包含 `.trellis/tasks/` 目录下的文件变更。

## 实现

- PR 创建、重新打开、编辑描述、推送提交和转为待审时重新检查。
- 使用 PR 分支与目标分支的共同祖先计算差异，纳入嵌套任务文件及较早提交中的变更。
- 勾选且缺少记录时，由 `noraincity-bot` 用现有 `BOT_ACCESS_TOKEN` 提交要求更改的审查。补交记录或取消勾选后，撤销该门禁此前提交的审查。
- 工作流在 GitHub 托管运行器中读取 PR 元数据及 Git 对象，Git 仓库使用裸仓库模式。

## 验证

- 本地 Git 差异和模拟 GitHub API 测试通过，覆盖未勾选、勾选且缺少记录、嵌套记录、较早提交中的记录、重复触发、自动撤销和机器人身份验证。
- GitHub 端验证待工作流进入默认分支并配置目标分支的审查规则后进行。
